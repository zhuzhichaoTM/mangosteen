# 图标说明

## 图标要求

- 格式：PNG 或 SVG
- 尺寸：512x512 px（推荐）
- 背景：透明或白色
- 风格：简洁、现代、易识别

## 图标设计建议

### 主题
- 大模型/推理相关
- 云端/本地部署
- 芒果（Mangosteen）元素

### 色彩
- 主色：橙色/黄色（芒果色）
- 辅色：蓝色（云端）、绿色（本地）

### 设计元素
- 芒果图标 + 云朵
- 芒果图标 + 服务器
- 简化的 M 字母 + 云端符号

## 临时方案

如果暂时没有设计图标，可以：
1. 使用默认图标（WorkBuddy 会使用默认占位符）
2. 使用简单的文字图标（如 "ML" 或 "MD"）
3. 从开源图标库选择相关图标

## 添加图标

将图标文件命名为 `icon.png` 或 `icon.svg`，放置在本目录下。
