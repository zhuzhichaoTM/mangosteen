- 用完说"停止"，计费立刻归零

## 三、日常使用：三个动作

### 动作 1：部署

对 AI 说：

> 部署标准版 qwen3.8-27b

AI 会自动完成：扫描最便宜可用 GPU → 向你确认价格 → 开机 → 下载模型 → 拉起推理服务。

**耗时预期**：

| 场景            | 耗时      | 说明              |
| ------------- | ------- | --------------- |
| 首次部署（或实例被销毁后） | 约 12 分钟 | 大头是模型下载（15.7GB） |
| 复用部署（实例只是关过机） | 约 5 分钟  | 模型已缓存，只需加载      |

期间不需要你做任何事，AI 会持续汇报进度。

### 动作 2：使用

部署完成后，AI 会给你一个 API 地址：

> <http://127.0.0.1:11516/v1>

**OpenAI 兼容接口**，任何支持自定义 API 的工具都能接（LangChain、LlamaIndex、各类客户端、你自己的代码）。

最小调用示例：

```bash
curl http://127.0.0.1:11516/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3.8-27b",
    "messages": [{"role": "user", "content": "你好"}],
    "max_tokens": 256
  }'
```

**三个使用要点**：

1. **`max_tokens` 至少给 64**。qwen3.8 是推理模型，会先"思考"（思维链）再回答。给太小（如 16），token 全耗在思考上，你会收到一个看起来是空回复的结果。
2. **答案在 `content` 字段，思考过程在 `reasoning_content` 字段**。做对比测试、分析模型行为时，两个字段都要采集——思维链往往比答案本身信息量更大。
3. **上下文窗口 8192 tokens**（约 6000 汉字）。长文档测试注意分段。

性能参考（3090 实测）：生成速度约 58~74 tokens/秒，首 token 延迟 1 秒内。

### 动作 3：停止

**用完必须说**：

> 停止大模型

AI 会停止模型并关闭云实例，计费立刻归零（实测停止后 ¥0.00/h）。

**忘记停止的代价**：实例按 ¥1.13/小时持续计费，一天约 ¥27。建议测完就停，下次部署复用实例只要 5 分钟。

## 五、常见问题

**Q：部署日志里出现"算力降级 / 纯 CPU 推理"警告，模型是不是没用上显卡？**  
A：是显示误报，不影响使用。判断依据很简单：27B 模型纯 CPU 推理只有 2~5 tokens/秒，实测 58+ tokens/秒 就是显卡正常工作的证明。

**Q：能不能同时跑多个模型 / 多个实例？**  
A：可以开多台，但按台计费，成本翻倍。一般测试单台足够；需要对比不同模型时，可以串行：停掉 A → 部署 B。

**Q：实例长期不用，要销毁吗？**  
A：不用。关机（stop）后不计费，磁盘保留模型文件，下次部署直接复用、省 8 分钟下载时间。确定这个账号不再用了再说销毁。

**Q：回复是空的 / 只有一堆思考过程没有答案？**  
A：`max_tokens` 给太小了，加大到 64 以上重试。

**Q：部署到一半失败 / 卡住怎么办？**  
A：直接对 AI 说"重新部署"。失败台账会自动清理重建；已下载一半的模型支持断点续传，不会从零开始。

**Q：密钥可以给 AI 吗？安全吗？**  
A：可以。密钥只写入你本机的加密配置文件（权限 0600，仅你的账户可读），不会进入日志、不会外传。但别把密钥贴到公开网页、群聊里。

**Q：支持别的模型吗（如 DeepSeek、GLM）？**  
A：当前这个部署功能只支持 qwen3.8-27b 一个模型，别的模型不在支持范围内。
