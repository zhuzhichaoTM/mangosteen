设备选择

本地：全部资源都在本机，不产生费用。资源不足时会停止部署并说明原因，不会自动改用云端。
云端：全部资源都在云端实例，模型文件会同步到实例，按小时计费（部署前弹窗展示预估费用）。

推理引擎

llama.cpp（默认）：本项目拉起 llama-server 进程，单文件 GGUF，开箱即用。
Ollama：复用你已启动的 Ollama 服务（默认 11434 端口）， 不由本项目另行拉起——请先打开 Ollama 应用或执行 ollama serve。
vLLM / SGLang / TensorRT-LLM：需要 safetensors 或编译产物， 与本项目的模型台账不同，尚未适配——选中后部署会明确提示，不会静默失败。
